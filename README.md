# ScreenPilot Local 针对智慧树挂课出现的课堂问题，通过本地大模型实现图片识别+鼠标答题

> 让视觉 AI 在自己的电脑上运行。

**ScreenPilot Local** 是一个面向 Windows 的本地视觉 AI 项目，使用 **Qwen3-VL 8B** 理解视觉输入，并通过随程序提供的 **llama.cpp** 推理运行时执行模型。它的设计重点是让推理流程留在本机，减少对在线视觉服务的依赖。

项目由 **🐉🐉小龙娘GPT6-Astra 协助开发🐉🐉**，并由项目维护者负责测试、整合与发布。

## 项目特点

- **本地视觉推理**：使用 Qwen3-VL 8B 处理视觉信息。
- **独立运行时**：直接启动 `runtime/llama-server.exe` 并加载本地 GGUF 模型文件。
- **不依赖常驻 Ollama 服务**：即使模型文件最初来自本机 Ollama 缓存，打包后的运行路径也不需要调用 Ollama 服务或它的模型缓存。
- **本机通信**：推理服务监听回环地址（loopback），不作为对外开放的推理接口。
- **结构化结果**：使用 ChatML 提示格式及受 schema 约束的最终 JSON 输出。

> **隐私说明**：项目的视觉推理设计为在本地进行，不使用外部图像推理服务。这不等于对整个操作系统、其他程序或未来版本的所有网络行为作出保证。运行未知来源的二进制文件前，请自行核验发布者和文件。

## 如何使用

具体启动入口取决于发布包内的文件结构。请优先阅读相应版本 Release 附带的说明：

1. 下载与你的 Windows 设备匹配的.7z正式发布包
2. 解压到本地文件夹
3. 进入文件夹运行 ScreenPilot.exe 文件，程序会自动捕捉浏览器进程
4. 首次运行时，等待本地模型加载完成

**注意**：模型体积较大，电脑推荐显存VRAM不少于8G，实际内存、显存占用和推理速度取决于硬件、模型量化格式及运行配置。本项目不在此承诺固定的最低硬件要求或性能数值。

项目使用从已有本地 Ollama 模型缓存取得的 Qwen3-VL 模型文件，但正式运行时由独立 llama.cpp 程序加载这些 GGUF 文件，不依赖 Ollama 后台服务。

上述模型文件为**未经修改的副本**。其许可证及适用条件请参阅随项目附带的 `LICENSE-Qwen.txt`。

在 Windows PowerShell 中，可使用以下命令校验文件（替换为实际文件路径）：

```powershell

Get-FileHash "路径\视觉投影文件.gguf" -Algorithm SHA256
```

## 安全与局限

- 本地模型可能产生错误、不完整或不符合预期的回答。
- 请勿将模型输出直接视为可信的系统操作指令。
- 对任何涉及文件修改、终端命令、账户或系统设置的操作，都应保留人工检查环节。
- 回环地址监听不等于绝对隔离：本机其他进程仍可能访问相应服务。请避免在没有额外身份认证与网络限制的情况下将其开放到公网。
